# Paradise Nursery

## Project Name

Paradise Nursery Shopping Cart Application

## Project Description

Paradise Nursery is an online plant shop application that allows users to browse plants, view plant details, add plants to a shopping cart, and manage cart items.

## Features

* Browse different plants
* View plant names, descriptions, images, and prices
* Add plants to the shopping cart
* Increase or decrease item quantities
* Remove items from the cart
* Automatically calculate the total cost
* Navigate between different sections of the application

## Technologies Used

* HTML
* CSS
* JavaScript
* React
